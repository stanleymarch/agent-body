3. Companion Space CC0 VRMA motion set by Companion Space project
--------------------------------------------------------------
Bundled, unmodified: companion-listening.vrma, companion-thinking.vrma
These are existing reusable keyframed VRMA files generated by the upstream
project, not captured performances. Listening contains small head-pitch nods;
it is used as the closest available affirmative nod, not a bespoke yes clip.
Thinking is a subtle head/body thinking motion, not a hand-to-chin pose.

Runtime coverage
----------------
Actual file-backed cues: nod, think, bow. With gesture none: happy uses
encouragement, surprised uses startled reaction. Face expressions remain
independent. Idle and speaking use the Sachi files (speaking follows actual
setTalking audio activity and respects the idle-body-motion setting).
Wave/greeting and shake/no remain explicitly procedural: no permissively
redistributable source clip with sufficient exact provenance was found.
Any unavailable/failed file is reported in the console and its procedural
fallback remains available; a fallback must never be described as a VRMA.
